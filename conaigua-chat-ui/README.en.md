## Running the web interface

The web interface uses Docker to spin up the development environment in a controlled and reproducible way. The application is built with React and Next.js, and uses pnpm to install dependencies.

### 1. Install dependencies

First, install the frontend dependencies with the following command:

```
docker compose run --rm frontend sh -c "corepack enable && pnpm install"
```

### 2. Start the web interface

After installing the dependencies, you can start the web interface with:

```
docker compose up
```

Once the previous command has run, Docker starts the services needed to serve the web interface. From this interface, the user can interact with the system, make natural-language queries, and view the responses generated by the agent.
